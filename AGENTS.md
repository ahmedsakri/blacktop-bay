# Blacktop Bay

For every interface or visual change, follow [the mandatory UI quality standard](docs/ui-quality-standard.md). The user explicitly requires a consistent futuristic racing interface, illustrated icons, the approved palette, and usable desktop and mobile screens throughout the game.

Preserve working race physics, saved progression, privacy choices, licensed asset attribution, and keyboard/touch controls. Check relevant interactions and representative screen sizes before publishing. Publish only when no known critical defect or action overlap remains in those checks; never promise that software has zero possible bugs.

Development fixtures under `reports/` are for local review. Do not add them to the production build or describe a simulated fixture as a completed browser gameplay test.
